# 06. 사이즈 · 레이아웃 가이드

해상도, 간격 체계, 컴포넌트 크기, 라운드(radius), 컬럼 규칙을 담는다. 좌표를 잡을 때 참조하는 수치 정본은 prefab 이지만, 아래 값은 두 테마가 공유하는 표준이다.

> **디자이너 관점:** 좌표·크기의 정본은 prefab 이다. 값 미세 조정은 ✅ prefab(SceneMaker)에서, 코드에 하드코딩하지 않는다. 노드 추가/삭제·레이어 구조 변경은 ⚠️ 개발자 확인(→ `02`).

---

## 1. 해상도 · 프레임

| 항목 | 값 |
| --- | --- |
| 디자인 기준 해상도 | **1080 × 1920** (세로) |
| 화면 비율 | **9:16 고정** |
| 콘텐츠 폭 | **1040px** |
| 좌우 안전 여백 | **20px** (콘텐츠 레일 `x:20`) |
| 가로(옵션) | 1920 × 1080 (16:9), 세로 우선 설계 |

- 전체 UI는 하나의 프레임으로 균일 스케일. 개별 요소를 뷰포트별로 재배치하지 않는다.
- 레터박스는 검정 또는 배경보다 어두운 색. 표준 해상도일 때만 레터박스 생략.
- 좌표 공간은 **top-left (0,0)** 기준. 엔진이 center-origin 이면 `x' = x − 540`, `y' = y − 960`.

```ts
const DESIGN_WIDTH = 1080;
const DESIGN_HEIGHT = 1920;
```

## 6. 입력 스트로크(테두리) 규칙 — 중요

보더는 박스 바깥으로 번지지 않게 **inset stroke** 로 그린다.

```text
inset = strokeWidth / 2
1) roundRect(left, top, w, h, r).fill(INPUT)
2) roundRect(left+inset, top+inset, w−stroke, h−stroke, r−inset)
     .stroke({ color: STROKE, width: strokeWidth })
```

| 대상 | strokeWidth |
| --- | ---: |
| 일반 필드 | 2 |
| Base Bet · 키패드 디스플레이 | 3 |
| Selected accent | 2 |
| CANCEL 링 · CONFIRM | 3 |
| 디바이더 두께 | 3 |

## 7. 반응형 배경 (cover)

레터박스 여백 배경은 CSS `background-size: cover` 와 같은 계산을 쓴다. 종횡비를 유지하면서 대상을 완전히 덮는 최소 크기.

```ts
function coverSize(target, aspect) {
  if (aspect.width <= 0 || aspect.height <= 0) return { ...target };
  const scale = Math.max(target.width / aspect.width, target.height / aspect.height);
  return { width: aspect.width * scale, height: aspect.height * scale };
}
```

- **기준 종횡비는 prefab 노드의 저장 size** 를 호출부가 넘긴다(코드에 비율 하드코딩 금지).
- 배경 노드는 prefab 이 소유(예: `SprOuterBackground`). 코드가 Graphics 로 여백을 칠하지 않는다.

## 8. 좌표 정본 규칙

- 섹션 좌표(1080×1920 기준)의 **정본은 `raw-assets/game/prefabs/game.prefab` 하나뿐**이다.
- 같은 좌표를 코드에도 적어 두면 SceneMaker 에서 노드를 옮겼을 때 조용히 어긋난다 → 코드에 두지 않는다.
- prefab 골격 노드의 transform 을 읽어 `IRect{x,y,w,h}` 로 쓴다. 노드를 못 찾으면 dev 에서 즉시 던지고 운영에서는 로그 + 빈 rect 로 그 섹션만 비운다.

```ts
interface IRect { x: number; y: number; w: number; h: number; }
// prefabRect(panel, 'NodeName') → panel.findObject(name).transform 을 IRect 로
```
