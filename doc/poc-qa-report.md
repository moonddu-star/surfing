# TIDELINE POC QA 보고서

검수일: 2026-09-22. 대상: 독립 실행형 브라우저 POC. 최종 상용 서버·PixiBrown 템플릿 검수와 구분한다.

## 판정

수정 후 POC 검증 범위에서 차단 결함이 발견되지 않았다. 정산 단위·회귀 테스트 21개와 Chromium, Firefox, WebKit의 7개 화면 폭 검증이 통과했다. PC·모바일 화면 캡처를 시각 검수했다.

물리적인 iPhone·Android 기기 및 실제 Safari 앱을 검사한 결과는 아니다. 웹 엔진과 뷰포트 시뮬레이션을 사용했다.

## 검증 범위

### 정산·기록 21개 테스트

- 참가·취소·캐시아웃 중복 요청, 잔액 부족과 잘못된 금액.
- 1–100 CR의 모든 0.01 단위 참가금 9,901개에 대한 취소 정합성.
- 9,901개 참가금 × 대표 배수 10개의 지급액 99,010개 비교.
- 크래시와 동일 시점 거절, 직전 캐시아웃 보존, 즉시 크래시.
- 오래된 화면에서 들어온 참가·취소·캐시아웃 요청.
- 기록 100건·파도 이력 12건 제한 및 중복 정산 방지.
- 승인 직후 기록, 미래 크래시 값 비공개, 새로고침 복원.
- 미정산 상태의 잔액 초기화 차단, 손상된 저장 데이터 대응.

### 브라우저·레이아웃

| 엔진 | 화면 폭(px) | 결과 |
| --- | --- | --- |
| Chromium | 320, 360, 390, 520, 768, 1024, 1440 | 통과 |
| Firefox | 320, 360, 390, 520, 768, 1024, 1440 | 통과 |
| WebKit | 320, 360, 390, 520, 768, 1024, 1440 | 통과 |

가로 넘침 없음, Canvas 렌더링, 금액 입력 검증, 소수 금액 참가, 라이브 조작 유지, 태블릿 고정 CTA, 정산 즉시 로그, 새로고침 후 승인 결과 보존, Escape로 도움말 닫기, 사운드 토글 또는 미지원 안내, localStorage 접근 불가 시 플레이 가능 여부를 확인했다.

별도의 Chromium 전체 플레이 흐름에서는 참가 취소, 캐시아웃·개인 최고, 전체 크루, 기록, 테마·보드·피니시, 즉시 크래시, 모바일 고정 CTA 및 설정 복원을 확인한다.

## 재실행

```sh
npm ci
npm run check
npx playwright install chromium firefox webkit
npm run test:qa
```

`test:qa`는 4191 포트에 검수용 미리보기를 자동 실행하고 완료 후 종료한다. Linux 환경에서는 브라우저 설치에 `--with-deps`를 사용할 수 있다.

별도 전체 흐름 검증:

```sh
# 첫 터미널
npm run preview
# 두 번째 터미널
npm run test:browser
```

화면 캡처는 `tests/artifacts/`에 생성하며 저장소에는 대표 이미지 `doc/images/poc-desktop.png`, `doc/images/poc-mobile.png`만 보관한다.

## 후속 범위

상용 RTP 인증, 실제 현금·지갑·멀티플레이 서버, 네트워크 지연·재접속 계약, 친구 계정, 리플레이·클립, 실제 모바일 기기 검증은 이 POC의 완료 판정에 포함하지 않는다. [템플릿 전환 계획](pixibrown-migration.md)을 따라 후속 구현한다.
