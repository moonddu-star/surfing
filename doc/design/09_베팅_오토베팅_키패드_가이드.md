# 09. 베팅 · 오토베팅 · 키패드 가이드

베팅 UI, 프리셋/퀵버튼, 오토베팅(Basic/Advanced), 숫자 키패드 UX를 담는다. 이 시스템은 장르와 무관하게 그대로 이식 가능하다.

> **디자이너 관점:** 베팅 UI 의 **표시값·문구·프리셋/슬라이더 범위(서버 한도 이내)·비주얼**은 ✅ 조정 가능하다. 확률·배당·payload·베팅 한도 같은 **서버 계약 값**과 흐름 로직은 ⛔ 임의 변경 금지(→ `02`).

---

## 1. 베팅 기본 규칙

- 결과는 서버(또는 Local Mock)가 결정, 클라이언트는 요청·연출·표시만.
- 하우스 엣지 = `100% − RTP`. 배당 = `(RTP%) / winChance%` 형태(게임 공식에 맞게).
- 베팅 단위는 게임에 따라 다름(주사위 1개당 / 로켓 1개당 등). **총 베팅 = 단위 금액 × 개수 (+ 사이드)**.
- 금전 요청은 단일 진입점(`BetFlowController`)으로만. fail-closed(→ `02_아키텍처_상태_네트워크_가이드.md`).

### 1.1 공통 Config 항목 (게임별 값만 교체)

| Config | 예시 값 | 비고 |
| --- | --- | --- |
| `rtp` | 0.98 / 0.99 | 오퍼레이터 설정(빌드별 고정). 하우스엣지 = 1−RTP |
| `min_bet` | 0.01 | 1회 최소 베팅 |
| `max_bet` | 운영값 | 오토 상한 클램프 기준 |
| `default_bet` | 1.0 | 기본 베팅 |
| `min_count / max_count` | 1 / 100 | 동시 오브젝트 수(멀티 게임) |
| `default_count` | 2 | |
| `count_presets` | `[1, 2, 10, 50, 100]` | 프리셋 |
| `max_multiplier` | 게임별(예 10,000 / 9,900) | 이론상 최대 배율 |
| `max_exposure` | 운영값 | 최대 당첨(노출 한도) |
| `start_balance` | 1000 | 데모/프로토 전용 |

## 2. 베팅 UI 구성

### 2.1 값 입력 (2분할 연동)
- 예: `목표 배율(x)` ↔ `승률(%)` 를 공식으로 실시간 양방향 연동(`chance = RTP% / m`, `m = RTP% / chance`).
- 각 입력 아래 슬라이더: 값의 성격에 맞게 로그(배율) / 선형(승률).
- 전체 범위는 직접 입력, 슬라이더는 실용 구간(예: 배율 슬라이더 1.01x~1,000x, 입력은 ~10,000x).

### 2.2 개수 선택기 (멀티 게임)
- 슬라이더(min~max) + 직접 입력 + 퀵 프리셋 `[1][2][10][50][100]`. 기본 2.
- 변경 시 총 베팅금 즉시 갱신, 추천값 칩(예: 추천 목표 배율 = 개수 N) 갱신.

### 2.3 Bet Amount (금액 입력)
- 패널 `1040 × 226`, 입력 `1000 × 110`.
- 퀵버튼 `½` / `2×` / `Max` (Max = 잔액 기준, 멀티면 `잔액 / N`). 최소 0.01.
- 탭하면 숫자 키패드 오픈(§4).

### 2.4 보조 컨트롤
- **Turbo 토글:** 순차 연출 생략(일제 진행).
- **AUTO 버튼:** 오토베팅 팝업(§3).
- **총 베팅금 라벨** 강조. **BET** 풀와이드(오토 중 STOP 전환).

### 2.5 사이드 베팅(옵션)
- 메인 결과를 재사용하는 독립 정산 사이드 베팅을 둘 수 있다(예: 고배수 픽).
- 노출 한도(`maxExposure`)는 메인과 사이드 배당을 **합쳐서** 심사한다.

## 3. 오토베팅 (Basic / Advanced)

1회 설정으로 다수 라운드를 무인 반복. 두 탭으로 설정을 분리해 인지 부하를 낮춘다. **서버는 라운드 단위로만 관여하고 오토 루프 상태는 클라이언트가 관리**한다.

### 3.1 용어
| 용어 | 정의 |
| --- | --- |
| 라운드 | 1회 BET → 판정 → 정산까지의 단일 사이클. 오토 카운트는 **BET 1회 = 1라운드** |
| 오토 세션 | START ~ 정지 사이의 연속 라운드 묶음 |
| Base Bet | 세션 시작 시점 1회당 베팅(On Win/Loss 기준점) |
| Current Bet | 다음 라운드 실제 집행 1회당 베팅 |
| 세션 순수익 | 세션 시작 이후 `누적 당첨금 − 누적 베팅금` |

### 3.2 Basic 탭 — Number of Bets
- 프리셋 `10 / 25 / 50 / 75 / 100 / 500 / 1000 / ∞`. 기본 `10`.
- ∞: 유저 중지/정지 조건 전까지 무한 반복. 유한: STOP 버튼에 `남은 횟수 / 전체` 표기.

### 3.3 Advanced 탭
- **On Win / On Loss:** 직전 라운드 **순이익 부호**로 분기(`payout > totalBet` = Win).
  - `Reset`(기본): 다음 베팅 = Base Bet
  - `Increase by N%`: 다음 베팅 = 직전 × (1 + N/100), `N ∈ [0,100]`
  - Current Bet 최소 0.01 클램프, 상한은 `max_bet`.
- **Stop on Profit / Stop on Loss:** 금액 입력(빈 값/0 = 비활성). 매 라운드 정산 직후 판정.
  - `세션 순수익 ≥ Stop on Profit` → 정상 종료
  - `세션 순수익 ≤ −Stop on Loss` → 정상 종료

### 3.4 실행 규칙
```text
START:
  1. 설정 스냅샷 고정(Base Bet, 횟수, On Win/Loss %, Stop, 게임 파라미터)
  2. remaining = 횟수(∞면 무한), session_profit = 0, current_bet = Base Bet
  3. 팝업 닫힘 → 루프 시작. 메인 버튼 STOP 전환

루프:
  while (남은 횟수 > 0 또는 ∞) and (중지 요청 없음):
    (1) 잔고 검사: balance < 총 베팅 → 즉시 중단(잔고 부족)
    (2) 라운드 실행(베팅·판정·정산·연출·결과 팝업)
    (3) session_profit += (payout − totalBet); remaining -= 1
    (4) 정지 조건 판정
    (5) 다음 베팅 계산(순이익>0 → On Win, else On Loss, min 0.01)
    (6) 라운드 간 짧은 인터벌 후 반복
```

### 3.5 정지 조건 (순서대로 첫 매칭)
```text
(1) remaining == 0            → 정상 종료
(2) session_profit ≥ stop_on_profit  → 정상 종료(설정 시)
(3) session_profit ≤ -stop_on_loss   → 정상 종료(설정 시)
(4) balance < 다음 총 베팅    → 비정상 종료(잔고 부족)
(5) 유저 STOP                 → 즉시 종료
```
- 종료 시 **Base Bet 복원**, STOP → BET 전환.
- Disconnect 중이면 현재 라운드만 정산, 남은 오토는 모두 취소(자동 재개 미지원).

### 3.6 오토 중 UI 잠금
| UI | 상태 |
| --- | --- |
| 개수/목표값/승률/프리셋/퀵버튼/AUTO | 비활성 |
| 메인 버튼(STOP) | 활성(언제든 중지) |
| 오토 팝업 | 진행 시작과 함께 닫힘 |

### 3.7 값 저장 정책
| 항목 | 스코프 |
| --- | --- |
| 선택 탭 | 세션(재진입 시 Basic) |
| 횟수 / On Win / On Loss / Stop | 세션(마지막 값 유지) |
| Base Bet | 게임 공통 베팅 UI 규칙 |

## 4. 오토 시트 · 숫자 키패드 UX (이식용 스펙)

> 좌표는 1080×1920 top-left. Selected = fill alpha 0.5 + accent 2px + white label(별도 selected fill 색 금지). Hover = brightness 1.3. 인풋 보더는 항상 inset stroke.

### 4.1 AUTO 바텀시트
- 딤 `#030C1B @ 0.96`(뒤 UI가 비치지 않는 불투명도). 딤 탭 → 닫힘.
- 상단 설정 영역(탭 전환) + **하단 공유 푸터**(Base Bet / Total / START·CANCEL / Balance).
- **푸터는 라이브 하단 베팅 UI와 동일 절대 좌표에 덮어** 시트 오픈 시 컨트롤이 점프하지 않게 한다.
- 탭 전환: 카드 셸 모핑 + easeOutCubic(짧은 ease-out). **콘텐츠만 페이드**, 카드 배경은 불투명 유지(반투명 페이드 시 뒤 UI 비침).
- 주요 상수: 시트 여백 20, 카드 패딩 20, 내부 폭 1040/1000, ROW_HEIGHT 80, 탭 폭 510+gap 20, 칩 gap 12, half 필드 485 + 컬럼 gap 30.
- Action row: `START AUTOBET`(730×110, accent fill, ON_ACCENT 라벨) + `CANCEL`(250×110, teal 링).

### 4.2 숫자 키패드 (중앙 모달)
- 금액·배율·승률·오토%·Stop 을 동일 키패드로 입력. 딤 `#030C1B @ 0.90`.
- 시트 `843 × 985`, r=20, fill `CARD`. 콘텐츠 left 148.5, 폭 783, key gap 12.
- **디스플레이 안쪽 상단에 필드 타이틀(26/muted)을 숫자 위에 항상 표시**해 "지금 무엇을 고치는지" 유지.
  - 타이틀 맵 예: `Bet Amount` / `Base Bet` / `Target Multiplier` / `Win Chance` / `On Win` / `On Loss` / `Stop on Profit` / `Stop on Loss`.
- 키 그리드: 키 높이 110, r=12, fill `CHIP`, 폰트 50/white/center. **`0` 키는 두 자리 폭(518), `.` 는 한 자리 폭(253)**. C/Backspace 는 half(385.5).
- 하단 CONFIRM(783×110, teal 보더 3px inset).

### 4.3 키 동작
| 키 | 동작 |
| --- | --- |
| `0~9` | append; 현재가 `0`이면 교체; 최대 길이 12 |
| `.` | 소수점 1회만; 빈 값이면 `0.` |
| `C` | 전부 클리어 |
| Backspace | 한 글자 삭제 |
| Dim | cancel(값 폐기, 닫기) |
| CONFIRM | `Number(text)`가 finite 일 때만 적용 후 닫기 |

- 빈/`-` 초기값은 sanitize 후 `0`으로 시작(대시를 마이너스로 오인 방지).

## 5. 이식 체크리스트 (핵심 UX 규칙)

1. 좌표 공간 1080×1920 top-left(center-origin 엔진은 −540/−960 변환).
2. Selected = fill alpha 0.5 + accent 2px stroke + white label. 별도 selected fill 색 금지.
3. Hover = brightness 1.3. 딤/dismiss 면에는 hover 금지.
4. 인풋 보더는 항상 inset stroke(일반 2px, Base Bet/키패드 3px).
5. AUTO 푸터는 메인 베팅 바 좌표에 고정.
6. 탭 전환은 카드 셸 모핑 + 짧은 ease-out, 콘텐츠만 페이드.
7. 키패드는 중앙 모달, AUTO는 바텀 성장 시트, 둘 다 풀스크린 딤.
8. 키패드 디스플레이에 필드 타이틀 상시 표시.
9. `0` 키는 두 자리 폭, `.` 는 한 자리 폭.
10. 폰트 Bai Jamjuree Bold(또는 동일 무게 기하학적 산세리프).
