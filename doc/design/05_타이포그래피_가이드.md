# 05. 타이포그래피 가이드

서체, 역할별 크기/행간/굵기, 숫자 표기 규칙을 담는다. 새 게임은 이 역할 스케일을 그대로 재사용한다.

> **디자이너 관점:** 폰트 **크기·색**은 ✅ prefab `TypeMarkers` 값으로 바꾼다(코드 하드코딩 금지). **굵기·자간·줄간격**은 prefab 이 못 담아 코드 진입점이 가지므로 ⚠️ 개발자 확인(→ `02`).

---

## 1. 원칙 — 타이포의 정본도 prefab

- 타이포 토큰(`fontSize`, `fill`)의 **정본은 prefab 의 marker 노드**(`TypeMarkers`)다. 절차 생성 UI 도 여기서 읽는다.
- prefab 이 담는 것은 **`fontSize` · `fill` 까지**다. `fontFamily` · `fontWeight` · `letterSpacing` · `lineHeight` · `padding` 은 TextData 스키마에 없어 **런타임(코드) 몫**이다.
- 코드에 fontSize 기본값을 두지 않는다(marker 미전달 시 조용히 다른 크기로 그려지는 것 = 디자인 값 fallback). 부팅에서 전량 검증한다.
- `fontFamily` 를 런타임에 지정하는 이유: prefab 폰트 에셋이 atlas 별칭으로 바뀌면서 Regular 한 장만 묶여 faux bold 가 되기 때문. 진입점은 `shared/ui.ts`/`prefab-ui.ts` 헬퍼 하나로 모은다.

## 4. 역할 이름(마커) 참고

실제 게임에서 `TypeMarkers` 아래 역할 노드로 관리하는 이름 예시(게임마다 필요한 만큼 정의):

```text
베팅: TypeMetricValue, TypeMetricCap, TypeSliderValue, TypeBalanceValue,
      TypeSelectChip, TypeBetCtaAuto, TypeTurbo, TypeTotalBetValue ...
플레이: TypeCounterLabel, TypeCounterValue, TypeCounterSlash, TypeAxisLabel, TypeFloatLabel
결과 팝업: TypeResultCountNarrow, TypeSideTitle, TypeSideValue ...
메뉴: TypeHelpCopy, TypeHistoryCell ...
```

> 새 게임은 위 역할 중 필요한 것만 재사용하고, 게임 고유 텍스트(카운터·라벨)만 새 역할로 추가한다.

## 5. 숫자·텍스트 표기 규칙

1. 숫자는 **tabular(고정폭) 정렬**로 표기해 숫자 변경 시 폭이 흔들리지 않게 한다.
2. **숫자 문자열 길이가 변해도 중앙 정렬 블록의 중심점은 이동하지 않는다.**
3. 배율 표기는 `"수치x"` 형식(소수점 뒤 0 생략 가능, 통화별 자리 구분). 목표/결과 배율에 동일 적용.
4. 금액은 **통화별 규칙**(기호/코드, 표기 순서, 천단위 구분, 소수 둘째 자리)을 따른다. 리터럴(`'$'`)로 박지 않는다.
5. 섹션 라벨(BET AMOUNT, SIDE BETTING, DICE 등)은 **대문자** 표기.
6. 주요 값은 흰색, 라벨은 muted, 비활성 눈금은 disabled 색(→ `04_컬러_가이드.md`).

---

## 6. 값 리플로우 규칙 (라벨-값 쌍)

라벨과 값이 나란히 있을 때 값 폭에 맞춰 라벨을 재배치한다.

```text
Total Bet:  label.x = value.x − value.width − gap(30)
Balance:    label.x = value.x − value.width − gap(10)
```

- 값이 우측 정렬(anchor right)이면 라벨은 값 왼쪽에 gap 을 두고 붙인다.
- 무한(∞) 등 특수 값은 `-` 로 표기.
