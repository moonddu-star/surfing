# 11. 공통정책 · 로컬라이즈 가이드

RTP, 해상도 정책, 현지화, 히스토리/도움말, Freespin, Disconnect, 에러 코드 등 프로덕트 공통 정책을 담는다. 상세·최신 규격은 항상 사내 **Blitzcrown 프로덕트 공통 정책** 문서를 우선한다.

> **디자이너 관점:** 문구·현지화 키·도움말 본문은 ✅ 조정 가능(전 로케일 키 규칙 준수). RTP·해상도·Disconnect·에러 코드 처리 같은 **정책/계약**은 개발자·서버 영역이라 값을 임의로 바꾸지 않는다(→ `02`).

---

## 1. RTP

- RTP 는 오퍼레이터 설정이며 **RTP별 별도 빌드로 산출·납품**한다(게임 내 고정). 하우스 엣지 = `100% − RTP`.
- 예시 2단: `98% / 99%`(하우스 엣지 2% / 1%). Default 98%.
- 승률 상한/하한은 배율 범위로부터 자동 결정(예: `승률 상한 = RTP% / 최소배율`).
- RTP 값은 서버 `game_setting` 으로 내려오고, 부팅 설정 계약에서 고지 필드로 검증한다(→ `02` 문서 §5).

---

## 2. 해상도 정책

- 세로 `1080 × 1920` (9:16) 1종 기본 제작. 가로 `1920 × 1080` (16:9)은 선택.
- 화면 비율 항상 유지 + 레터박스(표준 해상도일 때만 생략). 가로/세로 분기점 1:1.
- 핵심 플레이 영역은 세로 기준으로 우선 설계.

---

## 3. 현지화 (Localization)

- **언어 31종**(미지원 시 영어), **통화 154종**(미지원 시 차단).
- 통화별 기호/코드·표기 순서·구분 기호·소수점 둘째 자리 규칙을 **베팅액·잔고·당첨금·히스토리·How to Play** 에 적용.
- 날짜 `YYYY-MM-DD`. 배율은 `"수치x"`(소수점 뒤 0 생략, 통화별 자리 구분).

### 3.1 언어키 정본
- 언어키 정본은 `raw-assets/localize/` 뿐. `game/<lang>.json`(게임) + `common/<lang>.json`(공용·서버 결과 코드).
- 전 로케일이 **같은 키 집합**을 유지해야 한다. 키를 늘리면 전 로케일 json 을 직접 맞춘다(별도 정본 시트 없음).
- 병합: `LocalizeSystem.loadLocale` 이 `common → game` 순서로 `Object.assign`, **같은 키는 game 이 이긴다**(의도된 오버라이드일 수 있으니 "중복"으로 지우지 않는다).
- 키 추가 순서: **전 로케일 json 에 키 반영 → 그 다음 코드·prefab 을 키 참조로 교체**(전 로케일에 없는 키에 의존하는 코드를 두지 않는다).
- 통화·금액을 리터럴(`'$'`, `'FUN'`)로 박지 않는다. 포맷 헬퍼(`formatCurrency*`, `formatKMBT*`) / `LocalizeSystem` 사용.

### 3.2 번역 대상이 아닌 곳 (영문 고정, 결함 아님)
- 히스토리 **상세 팝업**(히스토리 **목록**은 번역 대상 — 혼동 금지).
- 당첨 결과 팝업의 **등급 문구**: WIN / BIG WIN / MEGA WIN / SUPER MEGA WIN / EPIC WIN.
- 레이트리밋 안내는 공용 로케일에 문구가 없으므로 **유저에게 노출하지 않는다**.

## 4. 메뉴 — 도움말(How to Play)

- 언어별 HTML 제작(가이드 에디터). 항목 구성: 베팅 방법(수동/오토)·게임 규칙·페이아웃·RTP·연결 끊김.
- 본문은 현지화 키(예: `HELP_RULES`) 하나이며 팝업이 열릴 때마다 `game_setting` 값으로 치환한다.

### 4.1 도움말 본문 태그 규격
| 태그 | 동작 |
| --- | --- |
| `<data>필드명</data>` | `game_setting` 값을 포맷터로 치환 |
| `<visible={필드명}>…</visible>` | 필드가 참일 때만 블록 유지 |
| `<color={ffffff}>…</color>` | 글자색(hex 3·6·8자리) |

- **`visible`·`color` 는 중괄호 필수**(정규식이 요구). `<data>` 만 중괄호 없음.
- 치환 실패는 조용히 지우지 않고 **태그를 화면에 남긴다**(오배포 감지용). 도움말에 `<visible={...}>` 문자열이 보이면 번역 오타가 아니라 **서버 응답에 그 필드가 없다는 신호**.
- RTP 노출 여부 필드명은 **`visible_rtp` 로 통일**(서버 합의). 정규화(문자열 `'false'`/`'0'`/`''` 를 거짓 처리)는 팝업이 하므로 어댑터에 또 넣지 않는다.
- `<data>` 에 새 필드를 쓰려면 `types.ts` 의 `GameSetting` 과 팝업의 `RULE_FIELDS` **두 곳**에 추가.
- 번역문 태그 추가와 코드 변경은 **같은 커밋**으로 묶는다.
- 도움말 본문 번역 발주 시 UI 용어집(버튼 라벨 키와 번역)을 함께 넘긴다.

## 5. 메뉴 — 히스토리

- 게임 **비진행 중에만** 조회(직전 90일, 12건/페이지, 1·2차 팝업).
- **오토 진행 중·라운드 간 히스토리 버튼 비활성.**
- 세션 로컬 기록(새로고침에 사라짐)과 서버 페이지네이션 기록은 다르다 — 어느 쪽을 쓸지 게임 결정 사항.

---

## 6. Freespin (프리스핀)

- Free Bet 방식(고정 베팅금·지정 횟수)만 지원. 세션당 1개 활성(FIFO)·이어하기.
- 시작/결과 모달 팝업, 전용 UI(잔고 영역 → `TOTAL WIN`).
- 프리스핀 중 **오토 베팅·터보·베팅액 조절 비활성**. 히스토리에 `(Bonus)` 표기. 만료돼도 사용분 당첨금 보장.

---

## 7. 초기 진입 플로우

```text
다운로드(로고 + 로딩 바) → 타이틀 화면 → 튜토리얼 팝업(아무 곳 터치 시 닫힘·베팅 가능)
```
- 튜토리얼 팝업: 게임 타이틀 · 최대 당첨 배율(GLI 규정 — 최대 배율 확률 ≤ 1억분의 1일 때만 홍보) · Payout 핵심 규칙 안내.

---

## 8. Disconnect 정책

| 시점 | 처리 |
| --- | --- |
| 대기(IDLE) 중 끊김 | 공통 정책 준용 |
| 라운드 실행 중 끊김 | 현재 라운드만 정산 처리 후 종료 |
| 오토 베팅 중 끊김 | 현재 라운드만 정산, 남은 오토 라운드 모두 취소(자동 재개 미지원) |

- 금전 요청은 fail-closed. 자동 재접속을 쓰지 않고 **재시작 안내**(→ `02` 문서 §4).

---

## 9. 에러/예외 코드 (베팅·오토 관련 핵심)

| 코드 | 의미 | 게임 영향 |
| --- | --- | --- |
| `1310 BET_INVALID` | 라운드 상태 오류 | 베팅 거절 |
| `1393 INSUFFICIENT_BALANCE` | 잔고 부족 | 오토 중단 |
| `1420` | 과도 요청(레이트리밋) | rejected, 유저 미노출 |
| `API_ALERT_STOP_AUTO_PLAY` | 플랫폼 요청 오토 중지 | 오토 정지 |

- 서버 결과 코드 문구 정본은 `common/<lang>.json` 의 숫자 키. 게임 쪽에 같은 코드의 영문 표를 두면 드리프트가 생긴다.
- 공용 로케일에 문구가 없는 코드는 안내를 생략한다.

## 10. URL 파라미터 (공통)

| 파라미터 | 적용 | 설명 |
| --- | --- | --- |
| `server=local` / `server=real` | IS_DEV | 목업/실서버 강제 |
| `apiUrl=<url>` | IS_DEV | 실서버 URL 지정 |
| `operator` / `token` / `lang` / `currency` | 전 환경 | 로그인·표시 |
| `localize=v\|k\|kv` | 전 환경 | 로컬라이즈 값/키/키+값 표시 |
| `eruda=true` | non-production | 모바일 디버거 |
| `host=<kebab-case>` | dq | WebSocket 호스트 대체 |

- 기본 목업은 `localhost` + `project.config.ts` 의 `useLocalServer: true` 일 때만.
- 배포 호스트는 `Sequence.apiUrl` 이 구성. 클라 경로와 서버 이름이 다르면 `apiGameId` 를 별도로 둔다.
