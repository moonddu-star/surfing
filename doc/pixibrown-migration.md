# POC → PixiBrown 전환 계획

2026-09-22 사용자 지시: 템플릿 승인 전에는 지정 저장소에서 독립 POC를 먼저 완료하고, 이후 `doc/skills`와 `doc/design`에 맞춰 전환한다.

## 현재 POC의 역할

현재 구현은 HTML/CSS와 Canvas 2D로 플레이 흐름·시각 연출을 검증한다. `doc/skills/SKILL.md`의 최종 prefab 구조를 구현한 상태가 아니다. POC의 DOM·Canvas 코드를 최종 클라이언트 구조로 확정하지 않는다.

| 현재 파일 | 책임 | 전환 대상 |
| --- | --- | --- |
| `src/game-engine.js` | 로컬 공통 라운드, 데모 금액·정산, 크루 시뮬레이션, 개인 기록 | 확정 서버 계약 및 템플릿 로컬 서버. 수학·프로토콜은 별도 검증 |
| `src/main.js` | UI 이벤트, 표시, 설정·기록 저장, 사운드 트리거 | `src/game/`의 컴포넌트·GameMain 연동. `@Serialize`로 노드 연결 |
| `src/ocean-scene.js` | 절차적으로 그리는 파도, 서퍼, 탈출·와이프아웃 | 제공 PNG·Spine·애니메이션을 사용하는 prefab·씬 |
| `src/style.css` | POC 색·폰트·레이아웃·반응형 | 확정 디자인에 따른 prefab marker·레이아웃 값 |
| `index.html` | 화면 구조·조작부·대화상자 | `game.prefab`, 아이템 prefab, intro 공용 팝업 |
| `tests/game-engine.test.mjs` | 정산 경계·중복 요청·기록 테스트 | 실제 서버 계약에 맞춰 기대값을 재검증해 이식 |

## 전환 시 보존할 행동

- 참가 금액 차감·출발 전 취소·캐시아웃 지급을 중복 실행하지 않는다.
- 크래시와 캐시아웃이 경합하면 서버의 확정된 판정 규칙을 따른다.
- 캐시아웃 승인 후 연출이 지급액을 바꾸거나 지연시키지 않는다.
- 파도 연출은 공개된 배수·경과 시간에만 반응하고 미래 종료 시점을 암시하지 않는다.
- 참가자별 탈출 상태와 리스트 결과가 일치한다.
- 실제 정산 캐시아웃만 개인 최고 기록으로 인정한다.
- 파도 종료 배수와 내 캐시아웃 배수는 별도로 표시한다.
- 테마·보드·피니시 선택은 결과 분포에 영향을 주지 않는다.

## POC 전용으로 교체할 것

- 브라우저 로컬 엔진은 서버 권위를 제공하지 않는다. 실제 베팅·현금 서비스에 사용할 수 없다.
- 시작 잔액 1,000 CR, 1–100 CR 참가, 대기 8초, 결과 4.2초, 성장계수 0.105, 최대 50배는 **POC 시연값**이다.
- 일반 데모 분포의 0.99 계수는 상용 RTP 확정·보증이 아니다. 최소 배수, 절삭, 한도 및 캐시아웃 규칙까지 포함한 최종 수학 사양이 필요하다.
- 크루 6명은 로컬 시뮬레이션이며 실제 사용자 목록과 바꿔야 한다.
- 로컬 저장·새로고침 시 미정산 참가금 복원은 데모 편의 동작이다. 최종 재접속은 서버 잔고·라운드·정산 상태 복원을 따른다.
- POC 시나리오 선택과 잔액 초기화는 개발용 기능이다. 운영 사용자 화면에서 제거한다.
- HTML 대화상자는 최종 intro 공용 팝업을 대체하지 않는다.

## 템플릿 확보 후 적용 순서

1. 템플릿 지침과 실제 엔진·GameMain·로컬 서버 계약, 빌드 스크립트를 확인한다.
2. 서핑용 화면 레이아웃 및 개별 PNG·연출 자원을 확보한다. POC 캡처를 잘라 최종 이미지로 사용하지 않는다.
3. 확정 레이아웃을 측정해 `layout.md`를 작성한다.
4. `common`, `intro`, `game`, `localize` 번들과 기존 intro 구조를 보존한다.
5. 제공 에셋이 있는 UI부터 `game.prefab`·아이템 prefab으로 구성한다. 목록은 LayoutGroup·ScrollRect를 사용한다.
6. Container 루트의 입력 컴포넌트와 하위 Sprite 구조, `@Serialize`, 한 파일당 한 `@RegisterComponent` 규칙을 적용한다.
7. 에셋 변경 후 `npm run build:assets:dev`를 수행하고 SceneMaker 및 개발 서버에서 검증한다.
8. 서버 수학·정산·재접속 테스트와 PC·모바일 화면 검증을 완료한다.

공통 가이드에 남아 있는 Massive Mines·Avi-Cluck·Dice/Limbo 전용 규칙은 서핑 사양으로 가져오지 않는다.
