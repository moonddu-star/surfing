# 04. 컬러 가이드

색의 역할 체계와 두 가지 검증된 테마(Deep Blue / Neon Mint), 상태별 색 사용 규칙을 담는다. 새 게임은 이 **역할(role) 토큰 체계**를 그대로 쓰고 값만 테마에 맞춰 바꾼다.

> **디자이너 관점:** 색은 ✅ 안전하게 바꿀 수 있다. 단, **코드가 아니라 prefab `PaletteMarkers` 값**(SceneMaker/개발자)을 바꾼다. 새 토큰 이름 추가는 ⚠️ 개발자 확인(→ `02`, `10`).

---

## 1. 원칙 — 색의 정본은 prefab

- 색 토큰의 **정본은 prefab 의 marker 노드**(`PaletteMarkers`)다. 런타임은 읽어서 적용만 한다.
- **코드에 색 fallback 을 두지 않는다.** marker 가 없거나 값이 어긋나면 부팅에서 막고 알린다(색은 "경고 후 생략"이 성립하지 않아 부팅 게이트 한 곳에서 전량 검증).
- 중성 흰색(`0xffffff`)은 디자인 색이 아니라 마스크 채움·틴트 베이스용이므로 **팔레트 토큰이 아니다**(별도 이름 `NEUTRAL_WHITE` 로 둠).
- 상세 marker 규약은 `10_에셋_프리팹_가이드.md` 참조.

---

## 2. 역할(Role) 토큰 체계

게임과 무관하게 재사용하는 색 역할이다. 실제 게임 코드(`shared/palette.ts`)의 토큰을 역할별로 정리했다.

| 그룹 | 토큰 | 역할 |
| --- | --- | --- |
| 면·배경 | `bg` / `board` / `panel` / `surface` / `track` | 전체 배경 · 보드 · 패널 · 표면 · 트랙 |
| | `border` / `surfaceHighlight` / `divider` | 외곽선 · 표면 강조 · 구분선 |
| 강조 | `accent` / `accentHover` / `trackFill` | CTA·선택·활성 · hover · 슬라이더 진행 |
| 성공·실패 | `success` / `danger` / `dangerObject` / `dangerZone` | 승리 · 실패 · 실패 오브젝트 · 실패 영역 |
| 상태 | `warning` / `lucky` / `autoStop` / `menuIcon` / `iconHover` | 경고/Turbo · 사이드 · 오토 정지 · 아이콘 |
| 텍스트 | `text` / `textDark` / `muted` / `disabled` / `copy` | 본문 · 강조 위 다크 · 라벨 · 비활성 · 본문 보조 |
| 컨트롤 | `handleDetail` / `handleStroke` / `inputStroke` | 슬라이더 핸들 · 입력 테두리 |
| 상태 | `chipHover` / `chipPressed` / `cardPressed` | 칩/카드 인터랙션 |
| 히스토리 | `historyValue` / `historyLow` / `historyRowTop` | 히스토리 값·강조 |
| 게임 오브젝트 | (게임별) 예: `diceFlight` / `diceFace` | 핵심 오브젝트 색(게임마다 이름·개수 다름) |

> 새 게임에서는 "게임 오브젝트" 그룹만 게임에 맞는 이름으로 추가하고 나머지는 재사용한다.

## 3. 검증된 테마 A — Deep Blue

짙은 네이비 배경 + 블루 액션 + 흰색 숫자 중심의 고가독성 테마.

```css
:root[data-theme="deep-blue"] {
  --color-canvas: #051124;         /* 전체 화면·입력 내부·게임 배경 */
  --color-surface: #101b2d;        /* 주요 패널 */
  --color-raised: #0a1629;         /* 프리셋·비활성 컨트롤 */
  --color-border: #3c4c67;         /* 입력창 외곽선 */
  --color-track: #1e2b41;          /* 슬라이더 트랙 */
  --color-track-fill: #2457bf;     /* 슬라이더 진행·선택 테두리 */
  --color-action: #2661de;         /* BET 버튼·활성 토글 */
  --color-action-surface: #152950; /* Side Betting 배너 */
  --color-success: #26de82;        /* 승리·성공 */
  --color-success-light: #57ffab;
  --color-danger: #89373d;         /* 실패 기록 */
  --color-danger-bright: #ea4f59;
  --color-text: #ffffff;           /* 주요 값 */
  --color-text-muted: #4a5b78;     /* 라벨·보조 */
  --color-text-disabled: #273650;  /* 눈금·비활성 값 */
}
```

- 금지: Neon Mint 색(`#00FFC2`, `#09BF9C`, `#FFDE20`) 혼용, 임의 그림자/글로우/그라데이션.

## 4. 검증된 테마 B — Neon Mint

순수 검정 canvas + 민트 액션 + 노란색 Turbo 전용 강조의 고대비 테마.

```css
:root[data-theme="neon-mint"] {
  --color-canvas: #000000;         /* 화면 전체·입력 필드 내부 */
  --color-surface: #0f151c;        /* 주요 패널 */
  --color-raised: #18212b;         /* 프리셋·보조 컨트롤 */
  --color-raised-alt: #18212d;
  --color-border: #3c4c67;
  --color-track: #1e2b41;
  --color-accent: #00ffc2;         /* 선택·CTA·승리·활성 테두리 */
  --color-track-fill: #09bf9c;     /* 슬라이더 진행 */
  --color-warning: #ffde20;        /* Turbo 토글 전용 */
  --color-success: #00ffc2;
  --color-danger: #89373d;         /* 실패 기록 */
  --color-danger-object: #693f42;  /* 실패 오브젝트 */
  --color-text: #ffffff;
  --color-text-dark: #051124;      /* 민트 CTA 위 텍스트 */
  --color-text-muted: #4a5b78;
  --color-text-disabled: #273650;
}
```

민트(accent) 사용 제한(남용 금지):
- Primary CTA, 선택된 프리셋 테두리·텍스트, 활성 슬라이더, 승리 기록, 성공 오브젝트, Side Betting 배너 테두리에만.

노란색(`#FFDE20`)은 **Turbo 외에는 사용 금지**(일반 CTA·성공 상태에 쓰지 않는다).

## 5. AUTO/키패드 공유 팔레트

오토베팅 시트와 숫자 키패드는 별도 공유 팔레트를 쓴다(다른 장르에 그대로 이식 가능).

| Token | Hex | 용도 |
| --- | --- | --- |
| `DIM` | `#030C1B` | 전체 딤 · 인풋 채움 · 키패드 디스플레이 채움 |
| `CARD` | `#061328` | 카드·시트·CANCEL 내부 · 키패드 시트 |
| `CHIP` | `#12233D` | 칩·탭·퀵버튼·키 기본 채움 · 디바이더 |
| `ACCENT` | `#00FFC2` | 선택 보더 · START 채움 |
| `MUTED` | `#4A5B78` | 비선택 라벨·섹션 타이틀 |
| `STROKE` | `#3C4C67` | 인풋·디스플레이 보더 |
| `ON_ACCENT` | `#051124` | 민트 위 다크 라벨 |
| `TEAL_EDGE` | `#10CBA7` | CANCEL 링 · CONFIRM 보더 |
| `WHITE` | `#FFFFFF` | 선택 텍스트·숫자 값 |

- 딤 알파: AUTO 시트 `0.96`, 키패드 `0.90`.
- Hover: `brightness 1.3` 필터.

## 6. 상태별 색 매핑 (테마 무관 규칙)

| 상태 | Deep Blue | Neon Mint |
| --- | --- | --- |
| Default | surface + muted | `#18212B` + muted |
| Hover | 테두리 명도 소폭↑ | 테두리 명도 소폭↑ |
| Selected | `2px #2457BF` + 흰 텍스트 | `2px #00FFC2` + 민트 텍스트 |
| Active | `#2661DE` / `#2457BF` | `#00FFC2` / `#09BF9C` |
| Turbo | (action 계열) | `#FFDE20` |
| Success | `#26DE82` | `#00FFC2` |
| Loss | `#89373D` | `#89373D` |
| Disabled | `#273650`, 글로우 없음 | `#273650`, 글로우 없음 |
| Focus | 2px 포커스 링 | 2px 흰/민트 포커스 링 |

---

## 7. 컬러 사용 공통 규칙

1. **주요 값은 흰색(`#FFFFFF`), 라벨은 muted(`#4A5B78`), 비활성 눈금은 disabled(`#273650`).**
2. **성공/실패는 색으로 즉시 구분**되어야 한다(성공 = 강조/그린·민트, 실패 = 붉은/다크).
3. **강조색 남용 금지.** accent 는 선택·활성·성공 등 "의미 있는 순간"에만.
4. **결과 보드의 정보가 입력 패널보다 먼저 읽혀야** 한다(대비 확보).
5. 두 화면(예: 메인/사이드) 이상은 **동일 토큰을 공유**한다.
6. 테마를 섞지 않는다(테마별 금지색 목록 준수).
7. 색은 prefab marker 가 정본이므로, 새 값이 필요하면 코드가 아니라 marker 를 추가한다.
