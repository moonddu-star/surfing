# 08. 이펙트 · 연출 강도 가이드

장르와 무관하게 쓰는 공통 이펙트/사운드 **강도(1~10) 기준**과 화면 가림 규칙, 검수 규칙(GROK)을 담는다. 목표는 연출을 강하게 만드는 것이 아니라, 시퀀스와 보상 인지를 명확하게 만드는 것이다.

> **디자이너 관점:** 연출 강도·타이밍 조정은 ✅ 디자이너의 핵심 작업 영역이다. 단, 이 문서의 가림 규칙·GROK 을 반드시 지킨다(CTA·결과 금액·핵심 오브젝트를 가리면 실패).

> 사운드의 파일명/볼륨/ducking 세부는 `07_사운드_가이드.md` 와 함께 본다.

---

## 1. 공통 원칙

- 모든 연출은 게임 진행을 설명하거나 보상 감정을 강화해야 한다.
- 강한 연출이라도 **CTA · 베팅 버튼 · 재시작 버튼 · 잔액 · 보상 금액 · 핵심 판정 영역**을 가리면 실패한 연출이다.
- 이펙트 때문에 게임 시퀀스가 길어지면 안 된다. 연출은 기존 시퀀스 안에서 재생한다.
- 결과가 이미 결정된 게임에서 사운드·이펙트가 추가 판정처럼 보이면 안 된다.
- 테마 연출은 콘셉트에 맞아야 하고, 핵심 플레이 오브젝트보다 눈에 띄면 안 된다.
- 반복 플레이 게임은 1회 감동보다 **100회 반복 시 피로도가 낮은 것**이 더 중요하다.

## 2. 강도 스케일 (1~10)

| 강도 | 의미 | 이펙트 기준 | 사운드 기준 | 사용 빈도 |
| ---: | --- | --- | --- | --- |
| 1 | 거의 배경 | 미세 idle, 낮은 알파 | 아주 작은 ambience | 상시 |
| 2 | 약한 상태 인지 | 버튼 idle, 작은 glow | 부드러운 tick | 자주 |
| 3 | 일반 피드백 | 일반 클릭, 짧은 sparkle | click, tap, light hit | 자주 |
| 4 | 진행 변화 | 시퀀스 시작, 옵션 변경 | short whoosh | 자주 |
| 5 | 중간 보상 | 일반 win, 카운트업 시작 | win chime | 라운드당 |
| 6 | 강한 보상 | 고배수, 피쳐 진입, glow | stronger win | 조건부 |
| 7 | 매우 강한 보상 | Big Win, 국소 burst | big win accent | 드물게 |
| 8 | 대형 이벤트 | Mega급, 화면 강조 | large impact, fanfare | 매우 드물게 |
| 9 | 최고급 이벤트 | Epic/Ultra급 | peak fanfare, bass | 극히 드물게 |
| 10 | 최대 보상 | Max Win, Jackpot | maximum sting | 세션 내 희소 |

권장 기본값:
- 일반 입력/버튼: 이펙트 2~3, 사운드 2~3
- 일반 진행/충돌/이동: 2~4 / 2~4
- 일반 결과: 4~5 / 4~5
- 피쳐/고배수: 6~7 / 6~7
- Big Win 이상: 7~10 / 7~10

## 4. 화면 가림 기준

| 항목 | 허용 기준 |
| --- | --- |
| CTA 가림 | **0%** (full-screen particle/flare/fog 금지) |
| 핵심 결과 금액 가림 | **0%** (카운트업 중 금액 레이어 최상위 가독성) |
| 핵심 플레이 오브젝트 가림 | 최대 **10% 이하** (항상 추적 가능) |
| 베팅/잔액/주요 UI 가림 | 최대 10% 이하, 0.3초 이상 지속 금지 |
| 화면 전체 플래시 | 강도 7+ 에서만, 1회 0.08~0.15초 |
| 화면 전체 dim | Big Win 이상에서만. CTA/결과와 함께면 dim opacity 40% 이하 |

### 4.1 지속 시간

| 연출 유형 | 권장 | 최대 |
| --- | ---: | ---: |
| 버튼/UI 피드백 | 0.08~0.25초 | 0.3초 |
| 일반 충돌/판정 | 0.1~0.35초 | 0.5초 |
| 시퀀스 시작 cue | 0.25~0.6초 | 0.8초 |
| 일반 결과 | 0.4~1.0초 | 1.2초 |
| 피쳐 진입 | 0.6~1.2초 | 1.5초 |
| Big Win 시작 impact | 0.8~1.5초 | 2.0초 |
| Big Win 유지/카운트업 | 카운트업과 동기화 | 별도 대기 추가 금지 |
| Max Win peak | 1.0~2.0초 | 2.5초 |

핵심: **이펙트를 보여주려고 정산·다음 라운드·CTA 복귀를 늦추지 않는다.** 연출이 길어야 하면 카운트업/정산/결과 표시 시간 안에 포함한다.

### 4.2 강도별 화면 점유율

| 강도 | 권장 | 최대 |
| ---: | ---: | ---: |
| 1~2 | 1~5% | 8% |
| 3~4 | 5~12% | 15% |
| 5~6 | 12~25% | 30% |
| 7 | 25~40% | 45% |
| 8 | 35~55% | 60% |
| 9 | 45~70% | 75% |
| 10 | 60~85% | 90% |

단, CTA·결과 금액·핵심 판정 영역은 점유율 계산과 별개로 **가림 금지 영역**이다.

## 5. 콘셉트 일치

같은 강도라도 콘셉트별 표현이 달라야 한다.

| 콘셉트 | 이펙트 방향 | 사운드 방향 |
| --- | --- | --- |
| Halloween | 보라/오렌지 glow, 안개, 마법 파동 | 낮은 bell, ghost whoosh, 어두운 chime |
| Fantasy | 마법진, 별빛, 룬, 빛기둥 | harp, shimmer, orchestral swell |
| Sci-Fi | scan line, hologram, electric arc | synth beep, digital rise, clean impact |
| Casino | 금빛 sparkle, coin burst, spotlight | coin, chip, brass sting, slot chime |
| Cute Casual | 둥근 pop, pastel burst, bounce | soft pop, toy bell, light marimba |

금지: 콘셉트와 안 맞는 임시 효과음 방치, Cute 게임에 공포 저역 drone, Casino 에서 coin 사운드가 결과 판정을 오해시키는 것 등.

## 6. GROK 검수 규칙 (절대 기준)

하나라도 위반하면 강도를 낮추거나 위치/길이/레이어를 수정한다.

- **G — Gameplay First:** 핵심 플레이 오브젝트가 항상 보인다. 가림 최대 10%·0.3초 이하. 플레이어가 1초 안에 상황을 이해한다.
- **R — Readability Before Reward:** 결과 숫자·배수·상태 텍스트 가독성이 보상 연출보다 우선. 결과 금액·배수는 0% 가림. Big Win 이상에서도 숫자 레이어가 이펙트보다 앞.
- **O — Overlay Control:** CTA/베팅/재시작 버튼 위를 이펙트가 덮지 않음. 필수 UI 가림 최대 10%·0.3초. full-screen flash 는 강도 7+·0.15초 이내. dim 은 결과 집중용, CTA 필요 순간엔 40% 이하.
- **K — Keep Sequence Length:** 연출로 시퀀스 시간이 늘지 않음. 결과 표시·카운트업·정산·CTA 복귀 안에서 동시에 처리. 별도 감상 대기는 Big Win 이상에서만, CTA 복귀 막는 시간 2.0초 이하.

## 8. 검수 체크리스트

- [ ] 현재 시퀀스의 이펙트/사운드 강도가 1~10으로 표기되어 있는가?
- [ ] CTA·결과 금액·핵심 UI·핵심 플레이 오브젝트가 가려지지 않는가?
- [ ] 강도 7+ 연출이 너무 자주 반복되지 않는가?
- [ ] 연출 때문에 라운드 시간이 늘어나지 않았는가?
- [ ] 강한 사운드에 BGM ducking 이 지정되어 있는가?
- [ ] 반복 플레이 시 피로하지 않은가?
- [ ] 모바일 화면·작은 스피커에서도 가독성·음량 균형이 유지되는가?
