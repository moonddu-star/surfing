# 2D 횡스크롤 코어 장면

전환일: 2026-10-15. 사용자의 3D 중단 및 2D 횡스크롤 전환 요청을 반영한다.

## 화면 방향

서퍼를 옆에서 바라보며 오른쪽으로 달리는 구도다. 왼쪽에서 말려드는 파도, 중앙의 짙은 실루엣 서퍼, 오른쪽의 열린 수평선이 진행 방향을 보여준다. 하늘·섬·구름·먼 수면·가까운 물결·보드 뒤 물보라를 겹쳐 거리감을 만든다. 구름은 느리게, 수면과 앞쪽 물결은 빠르게 왼쪽으로 이동한다. 배수와 조작부는 고정한다.

데스크톱 기본 장면은 510~530px, 좁은 모바일은 440px 높이다. 몰입 보기로 확대할 수 있다. 모바일은 서퍼를 화면 안에 유지하고 캐시아웃 버튼은 기존 하단 고정 동작을 보존한다.

## 연출과 판정

| 상태 | 표현 |
| --- | --- |
| 대기 | 수평선과 파도가 흐르는 준비 장면, 출발 카운트다운 |
| 라이딩 | 큰 측면 서퍼, 보드 뒤 궤적과 물보라, 상승 배수 |
| 에어 피니시 | 보드와 함께 위로 뛰어 오른쪽으로 탈출 |
| 스프레이 턴 | 낮은 궤적으로 가속하며 큰 물보라를 남김 |
| 배럴 이스케이프 | 파도 앞면을 따라 오른쪽으로 빠져나감 |
| 크래시 | 확정 이벤트 이후 왼쪽에서 흰 포말이 밀려듦 |

캐시아웃 정산은 클릭 시 엔진에서 확정한다. 1.65초 피니시는 지급액이나 라운드 길이를 바꾸지 않는다. 파도 모양은 시간에 따른 미적 움직임이며 숨겨진 크래시 배수·크루 목표 배수를 읽지 않는다. 캐시아웃한 서퍼는 성공 연출 후 장면에서 사라진다.

모션 감소 설정에서는 배경·서퍼·피니시·크래시를 정적으로 표시한다. 배수, 버튼, 정산은 계속 갱신한다.

## 구현

- `src/side-scroll-scene.js`: Canvas 2D 레이어, 서퍼, 피니시, 테마, 크기 대응.
- `src/ocean-scene.js`: 기존 UI가 사용하는 클래스 진입점.
- `src/game-engine.js`: 변경하지 않은 라운드·금액·정산 엔진.
- Three.js·esbuild 및 3D 셰이더·서퍼 리그는 제거했다. WebGL 없이 동작한다.
- 빌드 시작 시 프로젝트의 `dist/`를 재생성해 이전 3D 파일이 배포물에 남지 않게 한다.
- 새벽·노을·달빛, 보드 4색, 피니시 3종과 기존 저장 설정을 보존한다.

현재 도형은 독립 POC용이다. 승인된 PixiBrown 템플릿과 아트가 제공되면 [전환 계획](pixibrown-migration.md)에 따라 prefab·Spine·제공 에셋으로 이식한다.

## 검수

`npm run check`, `npm run test:qa`, `npm run test:visual`, `npm run test:graphics`, `npm run test:browser`로 검사한다. 정산 단위 테스트 21개, Chromium·Firefox·WebKit의 7개 화면 폭, 세 테마·피니시, 모션 감소, WebGL 차단 환경, 장면 확대·축소 중 정산 보존, 비공개 결과 접근 금지를 포함한다. 캡처는 `tests/artifacts/visual/`, `tests/artifacts/side-scroll/`에 생성한다. 실제 모바일 기기의 프레임률 측정은 별도 후속 검수다.

## 실루엣 아트 방향

2026-10-15 추가 참고 이미지에 따라 피부·의상·얼굴의 내부 묘사를 제거하고 낮게 웅크린 측면 실루엣으로 바꿨다. 보드는 짙은 색으로 통일하되 가장자리의 얇은 라인으로 기존 컬러 선택을 유지한다. 노을은 주황색 하늘과 큰 태양, 짙은 청록색 파도, 역광을 받는 밝은 포말의 대비로 구성한다. 첫 방문 기본 테마는 노을이며 저장된 테마는 유지한다. `?theme=sunset` 링크로 노을을 선택해 열 수 있다. 제공 사진은 방향 참고용이며 파일을 게임에 포함하지 않는다.
