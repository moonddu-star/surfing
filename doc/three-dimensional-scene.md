# 3D 코어 장면

작성일: 2026-09-23. 이전 배럴 Canvas POC를 Three.js 0.186.0 / WebGL 2 장면으로 확장했다. 템플릿 승인 전 독립 POC이며, 정산 엔진과 서버 계약은 별개다.

## 장면 구성

- **파도:** 비대칭으로 휘어진 3D 곡면. 수면 변위, 다중 크기의 물결, 시선 각도에 따른 반사, 파도 끝의 포말을 셰이더로 표현한다.
- **바다:** 실제 장면을 낮은 해상도로 한 번 더 렌더링해 서퍼와 주변 환경을 수면에 반사한다. 반사에는 물결 왜곡과 작은 블러를 적용한다.
- **라이더:** 보드의 곡면·레일·데크 패드·핀·리시, 몸통·팔·다리 관절을 가진 절차적 3D 모델. 턴·무릎 굽힘·에어 자세를 분리했다.
- **카메라:** 대기 구도 → 낮은 추적 구도 → 피니시 추적 → 관전 복귀. 포인터에 의한 시차는 작게 제한한다.
- **환경:** 테마별 하늘·태양/달·조명·물 색, 파도 끝 물보라, 보드 트레일, 멀리 있는 시뮬레이션 크루.
- **크래시:** 확정 이벤트가 발생하면 파도가 내려앉고 수면이 카메라를 덮는다. 다음 대기에서 복구한다.
- **몰입 보기:** 화면 상단의 버튼으로 장면 높이를 확대한다. 조작 패널과 모바일 고정 캐시아웃은 계속 사용할 수 있다.

최종 아트 자산 없이 구현한 스타일화된 3D 장면이다. 실제 물리 유체 시뮬레이션이나 외부 캐릭터 모델을 사용하지 않는다. 후속 아트 모델 교체는 렌더러와 `SurferRig` 내부에서 진행할 수 있다.

## 모듈

| 파일 | 책임 |
| --- | --- |
| `src/ocean-scene.js` | 게임에 노출하는 장면 인터페이스, WebGL 지원 감지·복구 |
| `src/ocean-3d.js` | 파도 지오메트리, 카메라, 조명, 반사 패스, 입자, 상태별 연출 |
| `src/water-material.js` | 물·하늘 셰이더와 3개 테마 |
| `src/surfer-rig.js` | 보드와 관절 모델·포즈 |
| `src/canvas-scene.js` | WebGL 미지원·연결 손실 때 사용할 기존 2D 장면 |
| `scripts/prepare-runtime.mjs` | 고정된 Three.js를 로컬 단일 모듈로 압축하고 라이선스 복사 |

렌더러는 현재 phase·multiplier·bet·crew만 받는다. 미래 크래시 값과 크루의 목표 배수는 연출에 사용하지 않는다. 캐시아웃과 지급은 `game-engine.js`의 시간 판정에 따라 즉시 처리한다.

## 성능·접근성·복구

- 렌더링 픽셀 비율을 최대 1.5로 제한한다. 느린 프레임이 지속되면 최소 0.8까지 낮춘다. 저사양 단계에서는 추가 반사 패스를 생략하고 물 셰이더의 환경 반사를 사용한다.
- 반사 렌더 타깃은 최대 640×400이며, 주 화면과 별도로 낮은 해상도를 사용한다.
- 모션 감소 시 고정 카메라·고정 포즈를 사용한다. 상태나 외형이 바뀔 때만 3D 장면을 다시 그린다.
- WebGL을 지원하지 않거나 컨텍스트가 손실되면 캔버스를 교체하고 기존 장면으로 복귀한다. 게임의 참가·잔액·정산 상태는 렌더러 밖에 보존한다.
- Three.js와 폰트를 `dist/public/`에 함께 포함한다. 실행 중 외부 CDN을 호출하지 않는다.
- 자동 테스트에서 사용하는 소프트웨어 GPU는 실제 휴대폰 성능을 대변하지 않는다. 최종 아트 적용 이후 실제 기기에서도 검수해야 한다.

## 검수

- `npm run check`: 구문 검사, 기존 정산 회귀 테스트 21개, 정적 빌드.
- `npm run test:qa`: Chromium·Firefox·WebKit 및 7개 화면 폭. 실제 환경의 3D 또는 호환 경로에서 조작·기록·복원을 검사한다.
- `npm run test:visual`: WebGL 경로를 명시적으로 확인하고 3개 테마·피니시·모바일·크래시·다음 라운드·모션 감소를 검사한다.
- `npm run test:graphics`: 셰이더와 실제 3D 렌더링, 몰입 보기, PC/모바일 구도, 라이딩 중 컨텍스트 손실 후 캐시아웃, WebGL 미지원 시 참가를 검사한다.
- `npm run test:browser`: 참가·취소·정산·기록·테마·복원에 대한 게임 시나리오.

GitHub Actions의 QA·비주얼·그래픽 검사가 성공한 빌드만 Pages에 배포한다. 캡처는 `tests/artifacts/3d/`와 `tests/artifacts/visual/`에 저장한다.
